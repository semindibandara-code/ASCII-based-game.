OVERVIEW
----------------------------------------------------
This project implements a simple terminal-based escape
game written in C. The player moves through a map,
avoids traps and water, and tries to reach the goal.
The program demonstrates file I/O, gameplay logic,
flood fill (water spreading), and an undo feature using
a linked list. All requirements from the assignment
specification are implemented.


COMPILATION AND EXECUTION
----------------------------------------------------
To compile the program:
    make clean
    make

To run the game:
    ./escape map.txt

Controls:
    w - Move up
    s - Move down
    a - Move left
    d - Move right
    u - Undo last move

2. GAME INTERFACE
Files: game.c, util.c, color.c, terminal.c
Functions: draw(), apply_tile_color_begin(),
           apply_tile_color_end(), disableBuffer(),

Description:
    Displays the map with colored tiles:

        Green - Goal (G)

Status: FULLY FUNCTIONAL (minor flicker acceptable)

3. PLAYER MOVEMENT
Files: game.c
Functions: game_loop(), walkable()
Description:
    Player moves using WASD keys without pressing Enter.
    Movement stops at walls, trapdoors, and map borders.
Status: WORKING

----------------------------------------------------

4. TRAP INTERACTION
Files: game.c
Function: trigger_trap()
Description:
    Stepping on a trap (@) removes all traps and
    trapdoors (X). Enables water-spreading mode.
Status: WORKING

5. FLOOD FILL (WATER SPREAD)
Files: game.c
Function: flood_step()
Description:
    Implements a brute-force flood fill algorithm.
    Water (~) spreads to adjacent empty spaces after
    each player move once the trap is triggered.
Status: WORKING

----------------------------------------------------

6. WIN / LOSE CONDITIONS
Files: game.c, main.c
Function: game_loop()
Description:
    - Win: Player reaches the Goal (G)
    - Lose: Water reaches the Player
Status: FULLY FUNCTIONAL
